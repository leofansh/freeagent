## 1. 三十秒版

一个**跑在你自己机器上**的个人事务助手。

- 日常在**飞书**里跟它说话，或开 <http://127.0.0.1:8770/>
- 它管的是「今天该做什么」「这件事卡在谁那儿」「上次那个事后来怎么了」
- 它**不替你决定**优先级——只给带理由的确定性弱信号，你可以反驳
- 写代码的活它**不自己干**，而是派给 OpenCode，自己当闸门

## 2. 现在能干什么（已实现且有测试守着）

| 能力 | 入口 | 一句话 |
|---|---|---|
| 新建事务 | 飞书直接说/ `/new` | 自动推断角色与形状 |
| 今天视图 | `/today`、Web 首屏 | 先顺延，再全局排序，每条附理由 |
| 角色脉络 | `/roles` `/role` `/merge` | 角色是视图不是文件夹，事务可挂多个 |
| 状态流转 | `/start` `/pause` `/done` `/drop` | 三字段正交，互不覆盖 |
| 排期 | `/today-pin` `/followup` | 移出排期不改 `state` |
| 等候管理 | `/wait` | 记下在等谁，逾期会浮到上面 |
| 提醒 | 自动 + `/tick` | 两阶段（查 + 送达确认），不承诺恰好一次 |
| 恢复契约 | `/task` | 打开事务返回 7 项齐备，**≤2 轮**能开始下一步 |
| 透明弱排序 | `/today` `/plan` | 8 种信号，必标「启发式提示，不是评分」 |
| 草稿版本化 | `/draft` `/revise` `/accept` | 只填 `[TODO]`，不编造 |
| 记忆检索 | 服务层已就绪 | BM25 + 近期回落，**无向量**（要联网，刻意不做） |
| **事务硬删** | `/task-del`、Web 按钮/多选 | 不可恢复，两次确认，正在跑/有待批时拒 |
| 执行层履历 | `/feedback` | 只摆事实不给建议 |
| 连续性个人模型 | `/model` | 从记录现推的规律（完成时段 / 常顺延 / 卡住的等候 / 角色活跃度），只摆事实 |
| 待处理收集器 | `/pending` | 飞书收下的图片/文件落队，`/pending N` 一键澄清成事务；捕获不建事务 |
| 本地 Web | `python -m freeagent.web` | 四视图 + 详情页 + 委派实时面板 + 产出验收 |
| 委派闸门 | `/delegate` | 三道闸门在服务层，不在 UI |
| 执行期逐次授权 | 飞书卡片 / Web 面板 | 允许/拒绝/停止三路，沉默≠同意 |
| 产出验收 | Web 详情页 | 采纳 / 开新版本（没有「不合格」） |
| 执行器探针 | `/agents` | 只看不派：装了没、什么版本、能不能派 |
| 只读问答 | `/ask` | 不改文件、不建事务、不问审批 |
| 飞书通道 | 开机自启 | @ 门控 + 跨重启去重 + 白名单空则拒启动 |
| 配对 | `/pair <码>` | bot 私聊签发码，解决「怎么拿到 open_id」 |

## 3. 三层结构

```text
freeagent/
├── domain/      纯值对象，零 I/O、零业务判断
├── storage/     只存取，不判断（顺延/权重/迁移合法性都不在这层）
├── services/    全部业务规则与不变式 ← 闸门也在这里
├── llm/         LLMProvider 协议 + 规则兜底 + OpenAI 兼容客户端
├── cli/         REPL（终端）
├── web/         本地 Web（零框架零外部资源）
└── feishu/      远程通道：全仓唯一依赖 lark-oapi 的一层
      ↑
   app.py     依赖组装：CLI / Web / 测试共用同一条装配路径
```

三条纪律，改代码前先看：

1. `services` 承载全部业务规则。Web 层**不许**自己再算一遍顺延或排序。
2. `services/llm/provider.py` **不 import domain**——这是换真实 LLM 的接缝。
3. 核心包 **`dependencies = []`**，唯一第三方依赖是 pytest。断网必须照常能用。

## 4. 三个入口，对等

| 入口 | 怎么起| 特点 |
|---|---|---|
| **飞书** | 开机自启（启动文件夹放一个 `.cmd`） | 最省事，日常只需要它 |
| **Web** | `python -m freeagent.web` → `127.0.0.1:8770` | 零框架；**只监听回环**，其他地址直接抛错 |
| **终端** | `python -m freeagent.cli.app` | 角色合并、改名、静置等只能在终端 |

**通道之间不广播。** 一条事务在哪儿创建就在哪儿处理。

## 5. 怎么跑

```bat
REM 日常：飞书（开机自启，不用管）
REM 手动起桥接（会先跑 doctor 自检凭据）
tools\run_feishu.bat

REM Web 界面
set PYTHONIOENCODING=utf-8
set PYTHONPATH=src
python -m freeagent.web

REM 终端
set PYTHONIOENCODING=utf-8
set PYTHONPATH=src
python -m freeagent.cli.app
```

配 LLM（可选，不配也能跑通全部功能，只是分类靠规则）：

1. 环境变量优先：`set DEEPSEEK_API_KEY=sk-...`
2. 或落`~/.freeagent/llm.env`
3. `/llm` 看当前生效的是哪一个（**显示 Key 来源，不显示 Key**）

强制只走规则层（离线排查）：`set FREEAGENT_RULES_ONLY=1`
禁止自动降级（宁可报错）：`set FREEAGENT_ALLOW_FALLBACK=0`

## 6. 已知边界（会咬人的地方）

| # | 边界 | 后果 |
|---|---|---|
| 1 | **提醒是轮询式** | 两个进程都关就收不到。Web 界面**不解决**这个 |
| 2 | **飞书把文字当指令，非文字消息「收下而非丢弃」** | 图片/文件下载到 `attachments/` 并落入待处理收集器，`/pending` 列出、一键澄清成事务；富文本仍只回提示；都不建事务 |
| 3 | **授权卡的「停止」按钮真机未验** | 允许/拒绝已验（11 连点带真 message ID）；停止是信任关键路径 |
| 4 | **委派看得见 OpenCode 配置** | 放弃隔离后的代价（插件/MCP 列表不再屏蔽） |
| 5 | **白名单候选只有 OpenCode 注册表** | 全新目录在界面上没入口，只能手改 `config.json` |
| 6 | **Plan 模式状态只在内存** | 通道 LRU 淘汰会**静默丢弃**，回来发现助手失忆了 |
| 7 | **hermes 已登记未接线** | 一桶能力都不给。别以为多执行器可插拔已成立 |
| 8 | **关系对象是自由文本** | 「等张总」不可检索、不可聚合 |
| 9 | **角色知识写入入口未通** | 服务层就绪，CLI/Web 接线时再补 |
| 10 | **上下文无状态单轮** | 每次调用不带历史，上下文靠恢复契约显式提供 |

## 7. 几个反直觉的设计（别顺手"修好"）

| 现象 | 为什么故意的 |
|---|---|
| 排序不给出「就做这个」 | 用户无法反驳一个看不见的分数，但可以反驳一条带理由的信号 |
| 每条事务都挂「启发式提示，不是评分」 | 这句话是产品承诺，删了就是把判断权悄悄收回 |
| 委派时先问权限、再问模型 | 否则 LLM 会挑一个无权访问的项目满口答应，结果没做 |
| Web 只能建事务不能合并角色 | 合并不可逆且要能回看，这种操作留在能敲命令的地方 |
| 桥接状态显示「在跑但不是本界面启的」 | 合并成「在跑/没跑」等于把「管不着」谎报成「干净」 |
| 能杀进程的操作只挂 POST | 浏览器预取、爬虫、`<img src>` 都会自动发 GET |
| 白名单默认为空 | 白名单为空是**致命配置**，所以拒绝启动而不是默认放行 |
| 明文密钥落盘但不假装加密 | DPAPI 只防「其他 Windows 用户」，同用户进程照样能解；防那个的是会话令牌 |
| 委派禁止读 FreeAgent 自己的配置 | 否则执行器会把自己的 LLM 凭据反向读出来 |
| 冲突时以 `设计方案.md` 为准 | 它是逐字契约，`test_doc_contract.py` 守着 |

## 9. 改代码前

- 改**枚举、权重、阈值、命令表、文件树** → 必须同步改
  `docs/个人事务助手设计方案.md`，否则 `tests/test_doc_contract.py` 变红。
  改文档时记得它会做**逐字比对**与**双向校验**（文档列了不存在的文件、
  或存在没被列出的文件，都红）。
- 加**新功能** → 先看设计文档附录 B 的改进清单，别重复造。
- 涉及**不可逆动作** → 先确认 0.3 的十条底线（见重写版顶导览）没被破坏。
- 涉及**秘密** → 只走 `SecretStr` + 白名单文件引擎，别新增一条旁路。
